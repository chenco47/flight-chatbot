# Flight Company AI Chatbot

A lightweight conversational chatbot for airline customer support using GPT-3.5 Turbo.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Set environment variable: `export OPENAI_API_KEY=your_api_key_here`
3. Run: `python main.py`

## Features

- Conversational customer support interface
- Flight booking assistance
- Schedule and policy inquiries
- Persistent conversation memory
